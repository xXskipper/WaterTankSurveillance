Bill of Materials – Water Tank Surveillance System
===================================================

2x  Heltec WiFi LoRa 32 V4
      Chip      : ESP32-S3R2
      LoRa chip : SX1262
      Display   : 0.96" OLED (SSD1306, 128x64, I2C)
      Frequency : 868 MHz (EU)
      URL       : https://heltec.org/project/wifi-lora-32-v4/

2x  AZDelivery Polysilicon Mini Solar Panel
      Voltage : 5 V
      Power   : 1.5 W
      Notes   : Waterproof resin encapsulated

2x  3.7 V 3000 mAh LiPo Battery
      Connector : JST 1.25
      Protection: Built-in PCB
      Compatible with Heltec LoRa 32 JST connector

1x  ARCELI JSN-SR04T Waterproof Ultrasonic Distance Sensor
      Range    : 20 – 600 cm
      VCC      : 5 V
      Trigger  : 10 µs pulse on TRIG pin
      Echo     : HIGH pulse proportional to distance
      Notes    : IP67 suitable for outdoor/wet environments

Optional (not yet decided / not yet purchased) – Sender board only:
1x  Pressure sensor (water line)
      Type     : analog transmitter assumed, 0.5 – 4.5 V output, 5 V supply
      Notes    : output needs a voltage divider to max. 3.3 V for the ADC
                 (ratio in code: PRESSURE_DIVIDER, e.g. 10k + 20k = 1.5)
                 Sketch flag: FEATURE_PRESSURE

1x  Solenoid valve (refill)
      Type     : normally closed recommended (stays shut when power/ESP fails)
      Voltage  : open – 12/24 V or mains-side supply planned
      Notes    : switched via MOSFET or relay module with flyback diode and its own
                 supply; the ESP32 pin only drives the module's input.
                 Sketch flag: FEATURE_VALVE (needs FEATURE_PRESSURE)

===================================================
Pin Mapping – Heltec WiFi LoRa 32 V4 (ESP32-S3)
===================================================

LoRa (SX1262):
  SCK   → GPIO 9
  MISO  → GPIO 11
  MOSI  → GPIO 10
  CS    → GPIO 8
  RST   → GPIO 12
  DIO1  → GPIO 14
  BUSY  → GPIO 13

OLED (SSD1306, I2C):
  SDA   → GPIO 17
  SCL   → GPIO 18
  RST   → GPIO 21
  Addr  → 0x3C

Sensor (JSN-SR04T) – Sender board only:
  TRIG  → GPIO 4
  ECHO  → GPIO 5

Pressure sensor – Sender board only (placeholder pin, verify against the V4 pinout):
  Signal → GPIO 2 (ADC1) via voltage divider

Solenoid valve driver – Sender board only (placeholder pin, verify against the V4 pinout):
  Control → GPIO 6  (HIGH = open; swap VALVE_ON / VALVE_OFF for inverted modules)

Button (PRG/BOOT):
  Pin   → GPIO 0  (active LOW)
  Use   → Triggers manual display readout + link check on sender

===================================================
Feature flags (top of each sketch, 1 = on, 0 = off)
===================================================
Sender   : FEATURE_PRESSURE, FEATURE_VALVE (both default 0 until hardware is connected)
Receiver : FEATURE_EMAIL (master), FEATURE_EMAIL_LOW, FEATURE_EMAIL_FULL,
           FEATURE_EMAIL_TEST, FEATURE_EMAIL_VALVE

Refill logic (sender, FEATURE_VALVE): opens at fill <= 30 % and pressure >= 1.0 bar,
closes when full / >= 95 % / pressure < 0.3 bar / no valid level reading / after 240 min
(then locked until refilled above 30 % or button press). Checks every 2 min while open,
every 30 min otherwise.

LoRa payload: "level;pressure;valve"  (valve: 0 closed, 1 open, 2 locked)
              plain "level" when FEATURE_PRESSURE is off.
